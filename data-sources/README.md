# Проверка игровых данных

`valve-items-2026-09-09.json` — выборка числовых полей официального datafeed
Dota 2, полученная 9 сентября 2026 года. Для каждого предмета записаны URL и
SHA-256 полного ответа; неиспользуемые поля полного ответа в выборку не включены.
Контекст версии сверён с [официальным патчем 7.41e](https://www.dota2.com/patches/7.41e).

API отдаёт текущие данные и не является архивом конкретного патча. Поэтому
сохраняем датированный снимок и явно указываем дату проверки. Браузер игрока
не делает запросов к этому API.

Две дополнительные механики проверены по `desc_loc` официального ответа:

- [Tango](https://www.dota2.com/datafeed/itemdata?language=english&item_id=44):
  “Consuming an Ironwood Tree doubles the heal duration.”
- [Healing Salve](https://www.dota2.com/datafeed/itemdata?language=english&item_id=39):
  “Heals for half the amount per second when cast on an ally.”

На этих условиях основаны расчёты для Tango после Iron Branch и Healing Salve
на союзнике. Суммарное восстановление — скорость × полная длительность;
собственная регенерация и модификаторы исключены в условиях вопросов.

Новый патч требует новой проверки. Нельзя просто изменить номер версии на
старых значениях. Если источник противоречит игре или условия неоднозначны,
помечаем затронутый факт `needs-review` и исключаем его из тренировок.

## Справочник магазина

`valve-item-shop-2026-09-10.json.gz` содержит полные ответы `itemdata` для
250 предметов и чар. Архив собран 10 сентября; внутри у каждого ответа записана
собственная дата получения (9 или 10 сентября), URL и SHA-256 исходной строки.
Контекст каталога — 7.41e. Это датированный импорт, не архив API по номеру патча
и не ручная проверка каждого взаимодействия в игре.

Состав и порядок иконок соответствуют первому присланному фото магазина.
`src/data/item-shop-layout.json` задаёт группы; `item-shop-catalog.json` содержит
идентификаторы, названия и пути к иконкам. Детальные JSON сайта получаются через
`scripts/item-shop-data.mjs`: подстановка чисел из `special_values`, перевод
обозначений характеристик, удаление HTML и служебных кодов. Неизвестные параметры
помечаются, вместо них показывается многоточие. Тесты проверяют исходные хеши,
соответствие ID, цены и несколько преобразований значений.

Обновление подробных данных выполняется командой:

```bash
node scripts/import-item-shop.mjs
```

Для продолжения прерванного импорта можно добавить `--reuse-downloaded`.
Параметр `--cache-date=2026-09-09` разрешает повторно использовать скачанные
в этот день ответы из локального кеша; их дата получения сохраняется. Команда
не обновляет состав каталога и номер патча автоматически: их сверяют отдельно,
затем обновляют закреплённый снимок в тестах и запускают `npm run verify`.

`item-shop-icons-2026-09-09.json` записывает официальные CDN-адреса, размеры и
SHA-256 исходных PNG и WebP. Конверсия сохраняет размеры и альфа-канал.
Сжатые иконки находятся в `public/assets/item-shop/icons/`.

Фон `information-panel.png` — третий присланный владельцем PNG
(`52614821-0fe3-4399-a392-78a9554e1054.png`), скопированный без изменения пикселей.
Игровые изображения и тексты принадлежат соответствующим правообладателям.
