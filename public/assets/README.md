# Static assets

Сюда помещаются только статические файлы, которым нужен стабильный публичный URL.

Большие изображения карты и необязательные тяжёлые ресурсы не должны загружаться вместе с главной страницей.

`item-shop/` — 250 WebP-иконок Valve, отдельные JSON описаний и присланный
пользователем фон панели информации. Происхождение и контрольные суммы
описаны в `data-sources/`; раздел не загружает полные исходные ответы API.
