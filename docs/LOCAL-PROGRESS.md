# Локальный прогресс

Сохранение живёт в `localStorage` под ключом `dotareminder.progress.v1`. Аккаунт,
IP-адрес, идентификатор устройства, сервер и аналитика для этой функции не нужны.
UUID относится к тренировке, используется только для устранения дубликатов.

## Что сохраняем

- Один незавершённый тест: идентификаторы и порядок вопросов и вариантов,
  выбранный ответ, проверенные ответы и этап прохождения.
- До 50 последних завершённых тренировок, в том числе повторы ошибок.
- Вид тренировки, темы, время начала и обновления, патч и версия набора вопросов.

Описания предметов, картинки и сам справочник в сохранение не дублируются.
При восстановлении вопросы и правильные ответы берутся из проверенного набора.
Сохранённые оценки текущего набора пересчитываются, поэтому произвольное поле
`correct` в загруженном файле не меняет статистику.

Сохранение выполняется после каждого выбора и перехода, а также при открытии
нового теста. Завершение с тем же UUID не создаёт второй результат. Записи
ограничены десятью вопросами; историю показываем по десять результатов за раз.

## Обновление данных

Для изменения значений, вариантов или структуры вопросов повышаем `QuestionBank.id`,
даже если номер патча тот же. При новом патче обновляем и `patch`.
Продолжение и разбор доступны только для той же версии проверенных вопросов.
Результаты прежних версий остаются архивными; в статистику текущего набора не входят.
Неизвестные вопросы внутри якобы текущей версии исключаются при сверке сохранения.

## Импорт и экспорт

JSON содержит только поддерживаемые поля формата версии 1. Ограничение размера —
256 КиБ на файл; число тренировок, вопросов, вариантов, длины ID, даты, допустимые
состояния и связи ответов проверяются до записи. Некорректный импорт не меняет
текущий прогресс. Игровой текст или HTML из файла не импортируется.

История объединяется по UUID, сортируется по времени и ограничивается 50 записями
и 256 КиБ сериализованного JSON. Строковые значения формата состоят из ASCII,
поэтому строка в UTF-16 занимает не более 512 КиБ. Если максимальные длины ID
не позволяют уместить все 50 записей, удаляются самые старые.

Локальный незавершённый тест имеет приоритет над незавершённым тестом из файла.
Если копия содержит завершение этого же теста, оно заменяет его черновик. Импорт
не обеспечивает облачную синхронизацию. При одновременной игре в нескольких вкладках
действует последнее записанное сохранение; совместное редактирование не реализовано.

## Ошибки браузерного хранилища

Ошибка чтения, запрет записи или исчерпание квоты не прерывают игру. Текущий прогресс
остаётся в памяти открытой страницы, показывается сообщение и доступен экспорт.
При возврате в меню старая копия с диска не заменяет новые несохранённые ответы.
После перезагрузки страницы память теряется; экспорт нужен до закрытия.

Очистка удаляет только ключ DotaReminder. При невозможности удалить или перезаписать
его показываем ошибку и объясняем, что старая копия может вернуться после перезагрузки.
Сброс требует явного выбора кнопки удаления внутри экрана прогресса.

## Проверка

`tests/progress.test.mjs` проходит полный раунд с сериализацией и восстановлением
после каждого действия, проверяет повтор из истории, пересчёт оценки, архивные
патчи, размер и формат импорта, объединение, ограничение истории, квоту и очистку.
Проверки модели не заменяют проверку поведения в реальном браузере.
