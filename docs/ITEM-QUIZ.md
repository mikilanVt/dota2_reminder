# Тест по предметам

Банк для 7.41e содержит 1270 вопросов по 233 предметам. Он расширяет исходные
14 вопросов, сохраняя их факты, варианты и ID. Сохранения продолжают работать.

| Тема | Вопросов |
| --- | ---: |
| Название по иконке | 233 |
| Стоимость | 184 |
| Собственные бонусы | 348 |
| Расход маны | 102 |
| Перезарядка активного применения | 91 |
| Эффекты, длительности, заряды и специальные случаи | 167 |
| Урон | 15 |
| Возможность развеивания | 32 |
| Разряд | 49 |
| Начало доступности | 49 |

Каждый обычный раунд выбирает 10 разных предметов с разными темами. При повторе
ошибок используются только выбранные неверно отвеченные вопросы. Варианты
перемешиваются; текстовые ответы допускают 2–4 варианта, числовые — четыре.

У каждого вопроса есть иконка из справочника. В задании на название ответ не
раскрывается в подписи или alt до проверки. Ошибка загрузки блокирует ответ
на узнавание и предлагает повторить загрузку. Картинки есть и в разборе ошибок.

## Ограничения содержания

Не спрашиваем категории магазина, тип применения, радиус/дальность, полезность
в билде и название способности. Тип урона, возможность развеять эффект и
развеивание при использовании — разрешённые механики.

Текущий пул: все 184 обычных предмета каталога и 49 нейтральных артефактов.
Рецепты, раздел особых предметов с архивными наградами и 19 чар с зависимыми
от разряда значениями не включены. Это не полный исторический архив Dota.

Числа с несколькими значениями не выбираются автоматически. Вручную описанные
исключения называют условие: первое/последующие применения BKB, максимальная
перезарядка Aeon Disk. Нулевая перезарядка предмета с зарядами не считается
временем восстановления заряда; для Holy Locket используется отдельное поле.
Собственный бонус предмета отделён от ауры, включения, поглощения и бонусов
от атрибутов. Для ближнего и дальнего боя написаны разные условия.

## Обновление и проверка

1. Снимки Valve и доказательства таймингов находятся в `data-sources/`.
2. Дополнительные формулировки и поля — в `item-quiz-editorial.mjs`.
3. `node scripts/build-item-quiz.mjs` сверяет патч, хеши, поля и текстовые
   свидетельства, затем создаёт `src/data/item-quiz.generated.json`.
4. `npm run verify` проверяет генерацию, варианты, исключённые темы, игровые
   числа, сохранения и размеры production-сборки.
5. При изменении существующего правильного ответа или порядка исходных
   вариантов увеличиваем ID банка. Простое добавление вопросов его не меняет.

Сырой импорт не превращается в произвольные вопросы: генератор использует
ограниченный набор полей и отдельный список редакционных механик. Недоступные
и непроверенные факты не должны попадать в новую версию банка.

Код теста и данные загружаются только при открытии тренировки или прогресса.
Картинки переиспользуются, API во время игры не вызываются. Для восстановления
сохранения собираются лишь его вопросы, а не все 1270 объектов с вариантами.
