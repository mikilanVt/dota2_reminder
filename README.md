# DotaReminder

DotaReminder — интерактивный справочник и тренажёр знаний Dota 2: герои, предметы, механики, тайминги, тесты и мини-игры.

## Текущий статус

Доступна первая мини-игра: **Тесты → Предметы → Найти игру**.

В стартовом наборе 14 проверенных вопросов по семи предметам для патча 7.41e.
Каждый раунд содержит 10 случайных вопросов, проверку ответа, объяснение,
итог и повтор ошибок. Источник и дата проверки доступны после ответа.

Вкладка **«Предметы»** работает как магазин Dota 2: основные, улучшения,
нейтральные предметы и чары. В первой версии 250 иконок по присланному образцу,
поиск по названиям и подробная информация о выбранном предмете. Справа — широкая
панель с отдельной прокруткой; на телефоне описание открывается окном.
Данные получены из Valve 9–10 сентября 2026 года; дата каждого ответа сохранена.
Рецепты, рекомендации по позициям и исторический архив будут добавляться отдельно.

Главное меню оформлено в стилистике клиента Dota 2 и дорабатывается по обратной
связи. Остальные режимы и справочники ещё готовятся.

Кнопка **«Мой прогресс»** на главной открывает историю последних 50 тренировок,
разбор и повтор ошибок, продолжение незавершённого теста, скачивание и загрузку
копии прогресса. Вопрос, порядок вариантов и выбранный ответ сохраняются между
посещениями. Старые версии вопросов отмечаются как архив и не входят в текущую
статистику. После обновления набора устаревший незавершённый тест нужно начать заново.

Сохранение работает в браузере без аккаунта и сервера. Оно не переносится между
устройствами автоматически и удаляется при очистке данных сайта. Копия в JSON
позволяет перенести результаты вручную. Если браузер блокирует запись, сайт
сообщает об этом и продолжает работать до перезагрузки.

[Открыть сайт](https://mikilanvt.github.io/dota2_reminder/)

## Стек

- React 19 + TypeScript.
- Vite 8 для dev-сервера и статической production-сборки.
- Обычный CSS без UI-фреймворка.
- Без обязательного backend, базы данных и регистрации.

## Требования

- Node.js 20.19+ (рекомендуется актуальная LTS-версия).
- npm 10+.

## Запуск

```bash
npm ci
npm run dev
```

## Проверки

```bash
npm run typecheck
npm run build
npm test
npm run check:size
npm run verify
```

`npm run verify` проверяет TypeScript, собирает production-версию, проверяет
логику тренировки, восстановление и перенос прогресса, данные и наличие иконок
справочника по сохранённым источникам Valve, затем
контролирует размер сборки. Эта же команда выполняется перед публикацией.

Код мини-игры, прогресса и набор вопросов загружаются только при запуске тренировки
или открытии «Моего прогресса».
Магазин тоже загружается отдельным модулем. Описания запрашиваются по одному,
в памяти остаётся не больше 12 карточек. 250 иконок WebP занимают около 377 KiB.
Сайт не обращается к API Valve во время просмотра или игры.

## Основная структура

- `src/app` — оболочка приложения.
- `src/data` — форматы и обработанные игровые данные.
- `data-sources` — датированные снимки источников для проверки, вне публичной сборки.
- `src/features` — независимые функции и тренировочные режимы.
- `src/shared` — общие стили, компоненты и утилиты.
- `public/assets` — статические ресурсы, которым не нужен импорт через TypeScript.
- `scripts` — проверки и инструменты обслуживания.
- `docs` — архитектурные и эксплуатационные документы.
- `tests` — проверки данных и полного цикла тренировки.

План разработки находится в [ROADMAP.md](ROADMAP.md), правила работы — в [AGENTS.md](AGENTS.md), бюджеты производительности — в [docs/PERFORMANCE.md](docs/PERFORMANCE.md).
