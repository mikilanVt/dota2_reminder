# Исходники оформления

В `topbar/` сохранены оригинальные PNG верхней панели. Они нужны для будущих
правок оформления и не включаются в production-сборку.

Сайт использует существующие WebP из `public/assets/`. Чёрная область под
панелью непрозрачна и в оригинальных PNG. Её скрывает CSS-контур
`.topbar-art`, сохраняя выступ логотипа и открывая фон страницы.

Координаты вкладок в `src/app/App.tsx` и контур в `src/app/app.css` привязаны
к исходному размеру панели 3840 × 328. При замене изображения нужно обновлять
их вместе, чтобы подписи и области нажатия совпадали с нарисованными вкладками.
