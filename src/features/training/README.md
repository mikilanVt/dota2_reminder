# Training feature

`engine.ts` создаёт сессию и обрабатывает выбор, проверку и переход между
вопросами. Ответ нельзя засчитать дважды или изменить после проверки.
В раунде 10 разных предметов и тем из большого банка: название по картинке,
цена, бонус, мана, перезарядка, эффект, урон, развеивание, разряд и тайминг.
Числовые и текстовые ответы имеют 2–4 различных варианта; в вопросах «да/нет»
нет искусственных дополнительных вариантов. Порядок перемешивается.
Повтор ошибок создаёт новую сессию только из неверно отвеченных вопросов.

`TrainingScreen.tsx` отображает тест, объяснения, источники и результат.
Его код, стили и набор данных загружаются при запуске, а не при открытии меню.
`QuestionImage.tsx` показывает существующие WebP справочника, скрывает название
в заданиях на узнавание до ответа и позволяет повторить неудачную загрузку.
Без картинки ответить на узнавание нельзя. Иконки не загружаются всем набором.
`TrainingHub.tsx` сохраняет раунд через локальный модуль прогресса; в сохранении
только ID, порядок вариантов и ответы. Первые 14 вопросов остаются совместимы.

`npm test` проверяет соответствие чисел снимку Valve, фильтрацию патчей,
целостность набора, запреты на темы, все иконки, смешанные ответы, старые сохранения
и полное прохождение с повтором ошибок. Браузерные проверки
не входят в эту команду.
