# Training feature

`engine.ts` создаёт сессию и обрабатывает выбор, проверку и переход между
вопросами. Ответ нельзя засчитать дважды или изменить после проверки.
Повтор ошибок создаёт новую сессию только из неверно отвеченных вопросов.

`TrainingScreen.tsx` отображает тест, объяснения, источники и результат.
Его код, стили и набор данных загружаются при запуске, а не при открытии меню.
Результаты живут в памяти текущего экрана; постоянного хранения пока нет.

`npm test` проверяет соответствие чисел снимку Valve, фильтрацию патчей,
целостность набора и полное прохождение с повтором ошибок. Браузерные проверки
не входят в эту команду.
