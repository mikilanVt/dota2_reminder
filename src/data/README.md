# Игровые данные

`types.ts` описывает сущности, проверенные факты и вопросы. `starter-items.ts`
содержит первый набор для патча 7.41e: 7 предметов и 14 вопросов.

Значения записаны у сущности один раз. Факты с суммарным восстановлением
вычисляются из скорости и длительности; вопросы ссылаются на факты по ID.
Неправильные варианты — редакционный материал, а не игровые данные.

У каждого факта есть условия, источник, дата и статус проверки, версия патча.
Факты с `needs-review` или другим патчем исключаются из тренировки.
Снимок числовых полей и примечания к источникам находятся в корневом
`data-sources/` и не попадают в публичную сборку.

Для новой темы добавляем сущности и проверенные факты по той же схеме. Наличие
типа `heroes` или `map` не означает, что соответствующая база уже заполнена.
